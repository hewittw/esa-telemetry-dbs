## Honorable mentions

- Tyler Hobbs *Flow Fields* (tylerxhobbs.com/words/flow-fields): generative hero drawn from the model's own latent field
- Vast (vastspace.com): dataset spec strip; Hermeus (hermeus.com): dual-value metrics "0.438 (vs 0.322)"
- Klim (klim.co.nz): type reference. Söhne/Tiempos are paid; free stand-ins are Inter Tight/Geist + Newsreader
- Lusion (lusion.co), Rejouice (rejouice.com): studios for the WebGL hero and deep-tech pacing
- Saronic (saronic.com): "Capabilities / Specifications" toggle could become a "Story / Technical" toggle (recruiters vs. peers)

## Patterns across all of them
1. One interaction carries the thesis (Planet zoom, iCOMAT before/after).
2. Numbered report sections; huge numbers with tiny units in one repeated template.
3. WebGL saved for one hero moment; SVG/canvas for the figures.
4. A fixed color per model, used the same way in every chart; one hot accent for anomalies.
5. Figures animate only while on screen, with a pause control.
