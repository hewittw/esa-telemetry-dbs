# Avoid List: Agent Defaults

Without direction, the agent samples from the "high-probability center." Every page here must look chosen.
Add to this list whenever a default shows up in our own work, named precisely enough to point at.

- Inter / Roboto / Arial / system-ui as the whole type system
- Purple or indigo gradients, especially on white
- White page + gray cards + soft drop shadow + 12–16px radius everywhere ("Default: safe, familiar, unchosen")
- Indigo/violet primary buttons (`bg-indigo-600`)
- Predictable SaaS layout: centered hero + 3 feature cards + CTA band
- Emoji used as icons
- Generic filler content ("Oat milk, coffee, lemons", lorem ipsum, "Project Alpha"); use real, specific content
- Accent color sprinkled on everything
- Equal spacing everywhere (no grouping)
- Removing focus outlines
- Extra sections, taglines, and badges that don't help the visitor
